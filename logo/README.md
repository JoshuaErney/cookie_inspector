# Logo

"Data lens": an indigo tile, a bitten cookie, and a magnifying glass whose lens shows rows of data.

| File | Use |
|---|---|
| `icon.svg` | Master with full detail. Source for the 48px, 128px and 1024px PNGs. |
| `icon-small.svg` | Simplified (fewer chips, thicker lens ring). Source for the 16px and 32px PNGs. |
| `icon-1024.png` | Full-size raster for marketing use. |
| `lockup-light.svg` / `.png` | Icon plus name for light backgrounds. The text is outlined, so no font is needed. |
| `lockup-dark.svg` / `.png` | The same for dark backgrounds. |

The extension's own icons are in `../icons/`. `icon128.png` has the artwork at 96 x 96 inside 16 px of transparent padding, as the Chrome Web Store asks; the other sizes fill the canvas.

Colors: tile gradient `#7C7FFB` to `#4A4CDB`, cookie `#F7B53D`, chips `#6B3818`, lens glass `#22257F`.
